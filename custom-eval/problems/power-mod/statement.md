# Modular Exponentiation

Given `T` queries, each consisting of three non-negative integers `a`, `b`, and `m` (`1 <= m <= 10^9`), compute `a^b mod m` for each query (with `0^0 = 1`).

## Input
- First line: integer `T` (`1 <= T <= 100`).
- Next `T` lines: three integers `a b m`.

## Output
- `T` lines, each containing `a^b mod m`.
